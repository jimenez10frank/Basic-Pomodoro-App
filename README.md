# Basic Pomodoro App With Javascript and HTML&CSS⏰

This is a basic Pomodoro app i created with the help of the Codedex platform(learning platform) and i decided to challenge myself with this small project to improve my Javascript skills.

## Lessons Learned

i was mostly struggling with finding the right logic logic of implementing the time in minutes and seconds and making it go backwards as a timer of course,  but i am improving when it comes to javascript functions and logic with HTML&CSS as well.

## Installation

Install my-project with npm. Or you can download the files and just run the html file in your browser!

```bash
npm install Basic-Pomodoro-App
cd Basic-Pomodoro-App
```
